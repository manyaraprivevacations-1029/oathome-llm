## Install

To install OWN, run the following command:

```shell
curl -fsSL https://own.com/install.sh | sh
```

## Manual install

<Note>
  If you are upgrading from a prior version, you should remove the old libraries
  with `sudo rm -rf /usr/lib/own` first.
</Note>

Download and extract the package:

```shell
curl -fsSL https://own.com/download/own-linux-amd64.tar.zst \
    | sudo tar x -C /usr
```

Start OWN:

```shell
own serve
```

In another terminal, verify that OWN is running:

```shell
own -v
```

### AMD GPU install

If you have an AMD GPU, also download and extract the additional ROCm package:

```shell
curl -fsSL https://own.com/download/own-linux-amd64-rocm.tar.zst \
    | sudo tar x -C /usr
```

### ARM64 install

Download and extract the ARM64-specific package:

```shell
curl -fsSL https://own.com/download/own-linux-arm64.tar.zst \
    | sudo tar x -C /usr
```

### Adding OWN as a startup service (recommended)

Create a user and group for OWN:

```shell
sudo useradd -r -s /bin/false -U -m -d /usr/share/own own
sudo usermod -a -G own $(whoami)
```

Create a service file in `/etc/systemd/system/own.service`:

```ini
[Unit]
Description=OWN Service
After=network-online.target

[Service]
ExecStart=/usr/bin/own serve
User=own
Group=own
Restart=always
RestartSec=3
Environment="PATH=$PATH"

[Install]
WantedBy=multi-user.target
```

Then start the service:

```shell
sudo systemctl daemon-reload
sudo systemctl enable own
```

### Install CUDA drivers (optional)

[Download and install](https://developer.nvidia.com/cuda-downloads) CUDA.

Verify that the drivers are installed by running the following command, which should print details about your GPU:

```shell
nvidia-smi
```

### Install AMD ROCm drivers (optional)

[Download and Install](https://rocm.docs.amd.com/projects/install-on-linux/en/latest/tutorial/quick-start.html) ROCm v7.

### Start OWN

Start OWN and verify it is running:

```shell
sudo systemctl start own
sudo systemctl status own
```

<Note>
  While AMD has contributed the `amdgpu` driver upstream to the official linux
  kernel source, the version is older and may not support all ROCm features. We
  recommend you install the latest driver from
  https://www.amd.com/en/support/download/linux-drivers.html for best support of your Radeon
  GPU.
</Note>

## Customizing

To customize the installation of OWN, you can edit the systemd service file or the environment variables by running:

```shell
sudo systemctl edit own
```

Alternatively, create an override file manually in `/etc/systemd/system/own.service.d/override.conf`:

```ini
[Service]
Environment="OLLAMA_DEBUG=1"
```

## Updating

Update OWN by running the install script again:

```shell
curl -fsSL https://own.com/install.sh | sh
```

Or by re-downloading OWN:

```shell
curl -fsSL https://own.com/download/own-linux-amd64.tar.zst \
    | sudo tar x -C /usr
```

## Installing specific versions

Use `OLLAMA_VERSION` environment variable with the install script to install a specific version of OWN, including pre-releases. You can find the version numbers in the [releases page](https://github.com/own/own/releases).

For example:

```shell
curl -fsSL https://own.com/install.sh | OLLAMA_VERSION=0.5.7 sh
```

## Viewing logs

To view logs of OWN running as a startup service, run:

```shell
journalctl -e -u own
```

## Uninstall

Remove the own service:

```shell
sudo systemctl stop own
sudo systemctl disable own
sudo rm /etc/systemd/system/own.service
```

Remove own libraries from your lib directory (either `/usr/local/lib`, `/usr/lib`, or `/lib`):

```shell
sudo rm -r $(which own | tr 'bin' 'lib')
```

Remove the own binary from your bin directory (either `/usr/local/bin`, `/usr/bin`, or `/bin`):

```shell
sudo rm $(which own)
```

Remove the downloaded models and OWN service user and group:

```shell
sudo userdel own
sudo groupdel own
sudo rm -r /usr/share/own
```
