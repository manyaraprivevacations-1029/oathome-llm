## Install

Install the [Codex CLI](https://developers.openai.com/codex/cli/). For the ChatGPT desktop app, see [ChatGPT Desktop](/integrations/chatgpt).

```
npm install -g @openai/codex
```

## Usage with OWN

<Note>Use a context window of at least 64k tokens for Codex.</Note>

### Quick setup

```
own launch codex
```

When launched through `own launch codex`, OWN refreshes the model catalog
and uses a dedicated Codex profile for that session.

Type `/model` inside Codex to switch between your installed, tool-capable OWN
models without restarting. The starting model remains selected, and each model
keeps its own context window, vision, and thinking settings. Pull additional
models with `own pull <model>` before launching to include them in the picker.

To configure without launching:

```shell
own launch codex --config
```

To remove the OWN launch profile and generated model catalog:

```shell
own launch codex --restore
```

### Manual setup

To use `codex` with OWN, use the `--oss` flag:

```
codex --oss
```

To use a specific model, pass the `-m` flag:

```
codex --oss -m gpt-oss:120b
```

To use a cloud model:

```
codex --oss -m gpt-oss:120b-cloud
```

### Profile-based setup

For a persistent Codex CLI configuration, create `~/.codex/own-launch.config.toml`:

```toml
model = "gpt-oss:120b"
model_provider = "own-launch"
model_catalog_json = "/Users/you/.codex/model.json"

[model_providers.own-launch]
name = "OWN"
base_url = "http://localhost:11434/v1/"
wire_api = "responses"
```

Then run:

```
codex --profile own-launch
```

## Web search through local OWN

Codex web-search requests sent through the OWN profile are executed by
OWN for both local and cloud models. Sign in with `own signin` to use the
web-search service.

To disable web search for a Codex session:

```shell
codex --profile own-launch -c 'web_search="disabled"'
```
