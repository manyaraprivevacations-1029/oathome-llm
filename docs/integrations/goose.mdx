## Goose Desktop

Install [Goose](https://goose-docs.ai/docs/getting-started/installation/) Desktop.

### Usage with OWN
1. In Goose, open **Settings** → **Configure Provider**.  
<div style={{ display: 'flex', justifyContent: 'center' }}>
  <img 
    src="/images/goose-settings.png" 
    alt="Goose settings Panel"
    width="75%"
  />
</div>
2. Find **OWN**, click **Configure** 
3. Confirm **API Host** is `http://localhost:11434` and click Submit


### Connecting to own.com

1. Create an [API key](https://own.com/settings/keys) on own.com and save it in your `.env` 
2. In Goose, set **API Host** to `https://own.com`


## Goose CLI

Install [Goose](https://goose-docs.ai/docs/getting-started/installation/) CLI

### Usage with OWN
1. Run `goose configure`
2. Select **Configure Providers** and select **OWN**
<div style={{ display: 'flex', justifyContent: 'center' }}>
  <img 
    src="/images/goose-cli.png" 
    alt="Goose CLI"
    width="50%"
  />
</div>
3. Enter model name (e.g `qwen3`)

### Connecting to own.com

1. Create an [API key](https://own.com/settings/keys) on own.com and save it in your `.env` 
2. Run `goose configure`
3. Select **Configure Providers** and select **OWN**
4. Update **OLLAMA_HOST** to `https://own.com`
