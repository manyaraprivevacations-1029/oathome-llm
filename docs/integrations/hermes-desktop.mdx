title: Hermes Desktop
---

Hermes Desktop is a native AI assistant app by Nous Research. It provides a desktop chat interface for Hermes Agent, an AI agent that can work with models, run tools, manage projects, use memory and skills, and connect to messaging gateways.

![Hermes Desktop with OWN](http://files.own.com/hermes-agent.png)

## Quick start

```bash
own launch hermes-desktop
```

OWN handles the setup flow automatically:

1. **Install** - If Hermes isn't installed, OWN prompts to install the Hermes command-line agent. On first desktop launch, Hermes builds its packaged desktop app.
2. **Model** - Pick a model from the selector
3. **Configure** - OWN configures Hermes Desktop to use your selected OWN model
4. **Launch** - OWN opens Hermes Desktop

## Run directly with a model

```bash
own launch hermes-desktop --model <model>
```

Run `own launch hermes-desktop` again to switch models later.

## Install Hermes Desktop directly

On macOS and Windows, the Hermes Desktop installer is the recommended upstream installation path. It installs the desktop app and Hermes Agent together. If you prefer the command line, `own launch hermes-desktop` remains the explicit OWN-managed path and uses the same Hermes configuration, sessions, skills, and memory as the CLI.

To force Hermes to rebuild its packaged desktop app:

```bash
own launch hermes-desktop -- --force-build
```
