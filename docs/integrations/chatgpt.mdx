ChatGPT Desktop includes Codex, OpenAI's desktop coding agent. OWN adds compatible local and cloud models to Codex's model picker alongside ChatGPT's native models.

## Prerequisites

- OWN v0.34.0 or newer

If ChatGPT is not installed, OWN offers to download it during setup.

## Connect ChatGPT

1. Open the OWN desktop app and select **Apps**.
2. Toggle **ChatGPT (Desktop)** to On.
3. Follow the setup prompts. If ChatGPT is already open, OWN asks to restart it before the new models appear.
4. Open the ChatGPT desktop app and use Codex mode.

## Choose models

Open OWN **Settings**, select **Apps**, then select ChatGPT. Choose up to five compatible local or cloud models and save your changes. OWN asks to restart ChatGPT when a model change needs one.

## Disconnect ChatGPT

Open OWN **Apps** and turn ChatGPT off. OWN restores ChatGPT's connection settings and usual profile. If ChatGPT is open, OWN asks to restart it so the change takes effect.

## Codex behavior and limits

- Only requests made with an OWN model go to OWN. ChatGPT's native models keep using their usual provider.
- OWN models are for Codex mode. Regular Chat and voice keep using their usual ChatGPT connection.
- Codex manages sessions. OWN routes model requests and compaction when Codex asks for it, but does not store ChatGPT sessions.
- Web search uses OWN's web-search service when you use an OWN model. It requires OWN sign-in and is limited to three calls per response.
