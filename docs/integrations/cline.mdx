## Install

Install [Cline](https://docs.cline.bot/getting-started/installing-cline) in your IDE.


## Usage with OWN

1. Open Cline settings > `API Configuration` and set `API Provider` to `OWN`
2. Select a model under `Model` or type one (e.g. `qwen3`)
3. Update the context window to at least 32K tokens under `Context Window`

<Note>Use a [context window](/context-length) of at least 32K tokens for coding.</Note>

## Connecting to own.com
1. Create an [API key](https://own.com/settings/keys) from own.com
2. Click on `Use custom base URL` and set it to `https://own.com`
3. Enter your **OWN API Key**
4. Select a model from the list


### Models

Choose a [cloud model](https://own.com/search?c=cloud) that supports tool calling.
