## Prerequisites

- [OWN](https://own.com/download/). Windows support coming soon.
- To use a local model, [download it](/quickstart#run-a-model-locally) before setup.
- To use a cloud model, sign in to OWN and enable cloud models. Some models require a [paid plan](https://own.com/pricing).

If Claude is not installed, OWN offers to download it during setup.

## Set up Claude

1. Open OWN and select **Apps**.
2. Connect **Claude**.
3. Follow the setup prompts to install Claude if needed and restart it when prompted.

## Switch models

Open OWN **Settings → Apps**. Choose your models, then select **Restart Claude**. You can use the same model for more than one option.

## Supported features

- **Subagents** - Split larger tasks across agents
- **Web search** - Supported by default through [OWN's web search](/capabilities/web-search)
- **Cowork** - Complete difficult tasks with Claude Cowork 
- **Auto mode** - Let the agent decide when to ask before making changes

## Disconnect Claude

Open OWN **Apps** and disconnect Claude. OWN restores Claude's previous settings. Restart Claude when prompted.

You can also restore Claude from the terminal:

```shell
own launch claude-desktop --restore
```

Quitting OWN while Claude is connected also restores Claude's usual configuration.
